# Synthetic data

Everything in this directory is **generated, not collected**. No file here
contains, is derived from, or was fitted directly to any real patient's
record — Indigenous or otherwise.

- `generate_equity_cohort.py` — the generator. Run it to (re)produce
  `equity_cohort.parquet`, a preview CSV, and a calibration report.
- `calibration_notes.md` — exactly which health-equity gaps modeled here
  are calibrated to a cited public statistic, which are only
  directionally motivated by one, and which are purely illustrative.
- `calibration_report.md` — generated output: the actual observed
  statistics from the current `equity_cohort.parquet`, compared against
  their calibration targets. Regenerated by the script; do not hand-edit.
- `equity_cohort.parquet`, `equity_cohort_preview.csv` — the generated
  cohort itself and a 50-row human-readable preview.

See
[docs/data-governance/ocap-and-privacy.md](../../docs/data-governance/ocap-and-privacy.md)
for why this project uses synthetic data calibrated against *public,
aggregate* statistics rather than any Indigenous patient-level dataset,
real or third-party.
