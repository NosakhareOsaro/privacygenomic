## [Unreleased]

### Added

- Project scaffold: `pyproject.toml` (uv-managed, Python 3.11–3.12), MIT
  license, pre-commit tooling (ruff, black, mypy), package skeleton for
  `equitable_rwe` (`cohort`, `survival`, `causal`, `fairness`, `ml`,
  `equity`), and repository documentation structure.
- `equitable_rwe.cohort`: MIMIC-IV to OMOP CDM v5.4 ETL
  (`person`, `observation_period`, `visit_occurrence`,
  `condition_occurrence`, `drug_exposure`, `measurement`, `death`) and an
  Achilles-style data quality module (referential integrity, date
  plausibility judged against the dataset's own clock, and standard
  vocabulary coverage checks). See `docs/architecture/adr-0001-omop-etl.md`
  for scope decisions.
- `data/synthetic/generate_equity_cohort.py`: synthetic Canadian
  chronic-disease cohort generator with two health-equity gaps calibrated
  to cited public statistics (2021 Census Indigenous population share;
  CIHI 2024–2025 rural/urban hospitalization rate ratio) and several
  further gaps directionally modeled and explicitly labeled as such — see
  `data/synthetic/calibration_notes.md`.
- `docs/data-governance/ocap-and-privacy.md`: OCAP® principles and the
  rationale for using only synthetic and public-aggregate data throughout
  this project.
- `equitable_rwe.survival`: Kaplan-Meier, Cox PH with a structured
  Schoenfeld-residual proportional-hazards test, a from-scratch Fine-Gray
  subdistribution hazard model (IPCW long-format construction on top of
  `lifelines.CoxTimeVaryingFitter`, since lifelines does not ship
  Fine-Gray) with an Aalen-Johansen cumulative incidence complement,
  a Royston-Parmar-family flexible parametric model (AFT-scale, via
  `lifelines.CRCSplineFitter`), landmark analysis, and bootstrap RMST
  differences. See `docs/architecture/adr-0002-survival-model-choices.md`
  for the trade-offs behind the Fine-Gray and Royston-Parmar
  implementations.
- `equitable_rwe.causal`: propensity score matching (scikit-learn-based,
  no R dependency), IPTW, a doubly-robust IPTW-weighted-and-adjusted Cox
  estimator, DoWhy backdoor adjustment with automated placebo/random-cause/
  data-subset refutation, and E-value sensitivity analysis. See
  `docs/architecture/adr-0003-causal-model-choices.md`.
- `benchmark/`: a four-estimator causal-adjustment benchmark (naive Cox,
  PSM, IPTW, DoWhy backdoor) on a synthetic cohort with a known,
  exact ground-truth hazard ratio, with E-value sensitivity analysis for
  every estimator. Results are committed and versioned
  (`benchmark/results/`), regenerated by `benchmark/run_benchmark.py`.
  On the current benchmark cohort, PSM and IPTW cut the naive
  estimator's log-scale bias relative to the true hazard ratio by
  roughly half or more (see `benchmark/results/benchmark_summary.md`
  for the exact, generated numbers).
- `equitable_rwe.ml`: an XGBoost 30-day readmission model
  (`fit_readmission_model`) with SHAP explainability
  (`explain_predictions`), deliberately excluding protected/proxy
  attributes from its feature set — see
  `data/synthetic/generate_readmission_cohort.py`.
- `equitable_rwe.fairness`: an AEQUITAS-equivalent classifier audit
  (`audit_fairness`: demographic parity via the four-fifths rule,
  equalized odds, within-group calibration), reimplemented directly on
  `numpy`/`pandas` rather than depending on the `aequitas` package, and
  a causal-estimator subgroup reliability audit
  (`audit_causal_subgroup_fairness`: per-subgroup effective sample size
  and post-weighting covariate balance for a doubly-robust survival
  estimate — a different, non-classifier notion of "fairness" that a
  hazard ratio actually admits). See
  `docs/architecture/adr-0004-fairness-and-ml-choices.md`.
- `equitable_rwe.fit_equitable_survival_estimate`: this project's
  headline API, combining the doubly-robust causal estimator with the
  causal subgroup fairness audit in one call, returning both a causal
  estimate and a fairness report.
